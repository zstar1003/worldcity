# 本地城市漫游 / 2026-10-22

用户已确认城市：北京、上海、广州、深圳。目标是在本机浏览器中实际加载原有彩色模型，并验证第一人称与第三人称漫游的可行性。

## 方案

使用 Three.js + glTF，静态资源由仅监听 127.0.0.1 的 Vite 服务提供。一次加载一座城市，切城释放 GPU 资源。保留原始几何，不做减面、顶点量化或贴图降分辨率；重复网格以 GPU 实例复用。记录源文件摘要、导出面数、资源与材质转换范围。源 Blender 文件不写入。

全屏实景画布，浅色紧凑控制面板，松绿强调色。顶部城市切换；底部自由观察、第一人称、第三人称切换。提供地标定位、返回起点、移动速度、画质选择与即时帧率。加载状态显示实际进度，失败可重试。桌面 WASD / 方向键移动，鼠标环视，Shift 加速；第一人称支持锁定鼠标；第三人称显示角色与跟随镜头。移动碰撞以已加载建筑网格验证，地面通过向下射线获取。

## 精度与现实边界

原模型为解释性建筑重建，并非实景扫描。浏览器 PBR 与 Cycles 离线光追不逐像素相同，程序化材质需转换或明确记录；实测后报告性能与效果。加载、碰撞和视角切换不能通过静态视频伪装。

## 验证

先完整深圳导出、加载、截图与移动验证，再接入其余三城。检查四城加载、资源释放、地标/视角切换、鼠标键盘控制、碰撞、窗口尺寸变化与控制台错误。测量几何数量、资源体积与运行帧率。保持本地预览运行供用户体验，不创建云端部署。
